## 功能

- 新建、编辑、删除任务，删除后立即撤销
- 完成任务和恢复待办，完成记录独立查看
- 标题、备注、截止日期与具体时间、普通／重要／紧急优先级
- 手机通知支持截止时、提前 5／15／30 分钟、1 小时、1 天，以及自定义提前天数／小时／分钟；点击通知打开任务
- 每天重复的任务按天记录完成情况，第二天自动恢复待办；设定具体时间后可每天提醒，当天完成不会停止明天的提醒
- 日期旁可选择“长期”，无截止日期的未完成任务常驻今日
- 自定义多标签，例如“购物、周末”，可在任务编辑页添加
- 生活、工作、学习、收集箱四个清单
- 今天展示所有未完成的未来任务、逾期任务、每日任务与长期任务；已完成栏展示今天完成的任务
- 计划页月历：有任务的日期显示圆点，点击日期在下方查看当天任务，可切换月份、跳转日期和回到今天
- 全部页顶部搜索框可动画展开为独立搜索页，按关键词、备注、清单名称或 `#标签` 查找，多个关键词可用空格分隔
- 搜索页内按清单、标签、截止日期范围、优先级和完成状态组合筛选，也可仅查看未设日期的任务；支持重置筛选
- 全部与计划页使用一致的状态选择样式，带选中背景和过渡动画
- 按截止日期、优先级、最近添加排序
- 今日完成进度、逾期标识、跟随系统深浅色主题
- 任务保存在本机，日期跨天和从后台恢复时自动刷新

设置截止日期与时间后可开启到期提醒。请允许通知权限；Android 12 及以上允许“闹钟和提醒”可获得准点通知，未授权时可能延迟，应用会提示。重启后自动恢复提醒；手机关机期间错过的提醒在恢复后补发一次。勿扰、系统省电及厂商后台限制可能影响提示效果；强制停止应用后需再次打开。

提前提醒需设置具体截止时间；自定义范围为 1 分钟至 365 天，单次任务的提醒时刻需在未来。每日任务可设置开始日期；每天独立勾选，不会复制出一串任务。长期任务完成后退出今日待办，可在全部页查找和恢复。

旧任务继续保留原日期和提醒，默认提前时长为零。暂不包含账号同步、按周／月重复、子任务和附件。
数据仅在应用私有目录保存，卸载或清除数据会删除任务。
