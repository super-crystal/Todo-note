# 拾光清单

一个简单、专注的中文 Android 待办应用，离线可用，无需账号。

## 功能

- 新建、编辑、删除任务，删除后立即撤销
- 完成任务和恢复待办，完成记录独立查看
- 标题、备注、截止日期、普通／重要／紧急优先级
- 自定义多标签，例如“购物、周末”，可在任务编辑页添加
- 生活、工作、学习、收集箱四个清单
- 今天（含逾期）、计划、全部三个视图
- 计划页月历：有任务的日期显示圆点，点击日期在下方查看当天任务，可切换月份、跳转日期和回到今天
- 全部页顶部搜索：按关键词、备注、清单名称或 `#标签` 查找，多个关键词可用空格分隔
- 按清单、标签、截止日期范围、优先级和完成状态组合筛选，也可仅查看未设日期的任务；支持重置筛选
- 按截止日期、优先级、最近添加排序
- 今日完成进度、逾期标识、跟随系统深浅色主题
- 任务保存在本机，日期跨天和从后台恢复时自动刷新

截止日期为日期级安排，**当前版本不发送系统通知**。暂不包含账号同步、重复任务、子任务和附件。
数据仅在应用私有目录保存，卸载或清除数据会删除任务。

## 功能参考

参考 [Todoist](https://www.todoist.com/help/todoist/features) 和 [TickTick](https://ticktick.com/features?language=en_us) 的任务、日期、优先级与清单功能，界面和实现为本项目独立编写。
